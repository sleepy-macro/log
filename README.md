# sleepymacro 公开交易日志与周刊（`sleepy-macro/log`）

> 本仓库是 [sleepymacro.com](https://sleepymacro.com) 的公开透明账本与研究推演归档，记录一个 `$10,000` 起始的**纯虚拟模拟实验（Paper Trading）**。
> **声明**：不荐股、不带单、不募资、不收费。

## 目录结构

| 路径 | 内容 |
|---|---|
| [`ledger/trades.jsonl`](ledger/trades.jsonl) | 按单号 `#001` 递增的交易交割单账本（含哈希链与 Arbitrum EAS 交易哈希） |
| [`trades/`](trades/) | 每笔交易按「推导链 / 认错与离场」记录的公开日志（持仓跨周后每周一补充跟踪） |
| [`issues/`](issues/) | 每周一发布上个自然周的周报（五格相关度关键新闻 + 下周财经日历，纯 Git 留痕） |

## 怎么核对链上交易存档

1. **链上机制（Arbitrum One · `chainId: 42161`）**：
   - 链上仅存不可篡改的**纯交易交割单**（买入/卖出时间、品种、数量、价格与资金变动）。每笔单据计算 SHA-256 指纹后，通过官方 EAS 合约 `0xbD75f629A22Dc1ceD33dDA0b68c546A1c035c458` 调用 `timestamp(bytes32)` 盖戳。
   - 交易笔记与周刊正文纯走 Git 留痕，不和链上格式绑死。
2. **网页端一键校验**：
   - 在网站总览页展开任意一笔交易，点击 **“本地校验 SHA-256”**，浏览器会直接对交割单原文重算指纹并与记录哈希比对；点击 **“Arbiscan 原件 ↗”** 可查链上交易 Input Data（末尾 32 字节即同一串指纹）。
